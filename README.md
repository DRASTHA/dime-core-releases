# DIME CORE - Roblox Studio ↔ VS Code Sync

Two-way sync between Roblox Studio and VS Code: scripts, instances, properties,
attributes and tags. By DIME PRODUCTION (drastxxx).

This repository only distributes the packaged releases.

## Install

1. Download the latest `dime-core-<version>.vsix` from [Releases](../../releases/latest).
2. VS Code → Extensions → `…` → **Install from VSIX…** → pick the file.
3. Open the folder you want to sync to, open the **DIME CORE** panel and click
   **Use This Workspace Folder**. Install the Studio plugin when offered and restart
   Roblox Studio.
4. In Studio, open **DIME CORE** (Plugins tab), paste the 6-digit code and press **Link**.

## Updates

DIME CORE updates itself — and its Studio plugin — whenever a new release is published
here. Run **DIME CORE: Check for Updates** to check right away, or set
`dimeCore.autoUpdate` to `notify` or `off`.
